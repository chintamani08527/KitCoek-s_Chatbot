SEMESTER V (THIRD YEAR - T.Y. B.TECH. CSE)
--------------------------------------------------------------------------------
Course Code: CS501
Course Title: Database Management Systems (DBMS)
Credits: 4 (3 Lectures + 2 Practical Hours)
Evaluation Scheme: In-Semester Evaluation (ISE): 40 Marks, End-Semester Examination (ESE): 60 Marks.

COURSE OBJECTIVES:
1. Understand relational database design principles and relational algebra.
2. Master SQL queries, transaction management, ACID properties, and concurrency control.

SYLLABUS UNITS:
- Unit 1: Introduction to DBMS Architecture & Data Models (6 Hours)
  Three-schema architecture, Data Independence, Entity-Relationship (ER) Modeling, Extended ER features, Relational Data Model and integrity constraints.
- Unit 2: Relational Query Languages & Advanced SQL (7 Hours)
  Relational Algebra operations, SQL DDL/DML, Complex Queries, Joins, Subqueries, Views, Triggers, Assertions, and Stored Procedures.
- Unit 3: Relational Database Design & Normalization (7 Hours)
  Pitfalls in relational design, Functional Dependencies, Normal Forms: First Normal Form (1NF), Second Normal Form (2NF), Third Normal Form (3NF), Boyce-Codd Normal Form (BCNF), Multi-valued dependencies and 4NF.
- Unit 4: Transaction Processing & Concurrency Control (7 Hours)
  Transaction concept, ACID properties, Serializability, Conflict vs View Serializability, Lock-based protocols (2PL, Strict 2PL), Timestamp-based ordering, Deadlock detection and recovery.
- Unit 5: Storage and Query Optimization (5 Hours)
  Indexing structures, B+ Trees, Hashing, Query Evaluation pipeline, Cost estimation, and Query Optimization heuristics.
- Unit 6: Modern & Distributed Databases (4 Hours)
  NoSQL databases (Document, Key-Value, Columnar, Graph), CAP Theorem, MongoDB basics.

IMPORTANT QUESTIONS / EXAM PREPARATION (CS501):
1. Explain 3-tier DBMS architecture and physical vs logical data independence.
2. Given a relation R(A,B,C,D,E) with functional dependencies, find the candidate key and decompose into BCNF/3NF.
3. Contrast Conflict Serializability with View Serializability with schedule examples.
4. Explain Two-Phase Locking (2PL) protocol and prove how it guarantees conflict serializability.
5. Describe B+ Tree insertion and deletion algorithms with node splitting.

Course Code: CS502
Course Title: Design and Analysis of Algorithms (DAA)
Credits: 4 (3 Lectures + 2 Practical Hours)
Evaluation Scheme: ISE: 40 Marks, ESE: 60 Marks.

SYLLABUS UNITS:
- Unit 1: Mathematical Foundations & Asymptotic Notations
  Order of growth, Big-Oh, Big-Omega, Theta notations, Master Theorem for recurrences.
- Unit 2: Divide and Conquer & Greedy Techniques
  Merge Sort, Quick Sort analysis, Fractional Knapsack, Huffman Coding, Prim's and Kruskal's MST.
- Unit 3: Dynamic Programming
  Principle of Optimality, 0/1 Knapsack, Longest Common Subsequence (LCS), Matrix Chain Multiplication.
- Unit 4: Backtracking and Branch & Bound
  N-Queens Problem, Subset Sum, Traveling Salesperson Problem (TSP) using LC Branch and Bound.
- Unit 5: Graph Algorithms & String Matching
  Bellman-Ford, Dijkstra, Floyd-Warshall, KMP Algorithm, Rabin-Karp.
- Unit 6: NP-Completeness & Approximation Algorithms
  P, NP, NP-Hard, NP-Complete classes, Cook's Theorem, Vertex Cover problem.
